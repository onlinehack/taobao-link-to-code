# taobao-link-to-code

把一个「链接 + 图文」的淘客作业页，原地转成可直接发群的**淘宝口令版文案**：结构、顺序、配图一律照抄原页面，只把 URL 换成口令。

> 这是一个 [WorkBuddy](https://www.workbuddy.cn) / Claude Code 风格的 **Agent Skill**。核心是 `SKILL.md`（写给 agent 读的说明书）+ 三个 Python 脚本（真正干活的部分）。你既可以把它当 skill 用，也可以直接命令行跑脚本。

## 它解决什么问题

作业页通常长这样：

```
𝟑𝟎𝟖-𝟑𝟒𝟗💰理肤泉𝐁𝟓𝐏𝐑𝐎 𝟔𝟎片
❶先领礼金
https://1.mlj94.com/xxxxxx
❷再去抄作业
https://1.mlj94.com/yyyyyy
```

这种链接直接发群里，别人点开还要自己找复制按钮，而且很多页面在微信里打不开。转成口令版之后就变成：

```
❶先领礼金
① 先领补贴礼金
8฿xxxx)/ CA39
② 再领优惠券
8฿xxxx)/ CA39
```

口令在微信笔记里还带**高亮底色**，一眼看出该复制哪一段。

## 产出三份文件

| 文件 | 用途 |
|---|---|
| `<name>_微信笔记.html` | 可编辑大白框，点「复制全部」连图带字进剪贴板；口令已高亮；图片没粘进去可以「图N」逐张补 |
| `<name>.md` | Markdown，块间 `---`，图片用远程 URL |
| `<name>_纯文本.txt` | 纯文字备份（纯文本没有格式，口令不带高亮） |

一次给多条链接时（比如「❶先领礼金 ❷抄作业」两条），`build_tabs.py` 会生成一个链接一个 tab 的版本，外加一个「全部」tab。

## 快速开始

```bash
pip install -r requirements.txt
playwright install chromium

# 1. 抓页面结构，下钻子链接拿口令
python scripts/extract.py "https://1.mlj94.com/xxxxxx" --out ./work --max-depth 3

# 2. 生成交付物
python scripts/build.py ./work/extract.json --outdir ./out --name "我的作业"

# 多条链接（先各自 extract，再合成数组）
python scripts/build_tabs.py ./all.json --outdir ./out --name "我的作业" --header "大标题"
```

作为 skill 使用：把整个目录放进 `~/.workbuddy/skills/taobao-link-to-code/`，之后直接对 agent 说「把这个作业链接转成口令版」即可。

## 支持的页面

| 形态 | 特征 | 处理 |
|---|---|---|
| **作业页** | 正文里有多个子链接 | 逐条下钻取口令，按原文顺序还原 |
| **单口令页** | 只有一个商品/券 | 标题 / 商品图 / 口令 |
| **图文合集页** | `mlj130.com/newCommunity?groupkey=…`，正文又带子链接 | **递归下钻并原地展开**，默认 2 层，`--max-depth` 可调 |

能认的口令形态：`$xxxx$` 老口令、`8￥ CZ0001 xxx￥://` 新版、`9฿xxx)/ CA66` 淘礼金/红包、以及跳转 URL 上的 `token` / `tk` 参数。

**一个链接对应多条口令时**（淘礼金页常常同时给「礼金 + 优惠券」），会自动在每条口令**上面**补一行说明（`① 先领补贴礼金` / `② 再领优惠券`），取自页面自己的按钮文案。

## 已知限制

- **页面改版就会失效。** 这类推广页的 DOM 说改就改，短链中转域也会换。失效属正常，欢迎提 issue 或直接改选择器。
- **京东链接没有口令。** 有些子链接跳到 `pro.m.jd.com/mall/active/...`（京东联盟券页），京东端不存在淘口令这种东西，脚本会保留原链接，不会硬造。
- **淘礼金口令每次访问会重新签。** 同一个礼金页抓两次，礼金那条码可能不一样（URL 里 `token` 稳定的是券那条），属正常。
- 需要页面本身可公开访问；要登录或已过期/风控的页面抓不到内容。

## 合规与免责

- 只处理**你有权分发**的页面内容；转出来的文案怎么用，责任在使用者。
- 口令里天然带着返利归因信息，**别把真实口令贴进公开仓库或公开示例**。本仓库示例一律用 `8฿xxxx)/ CA39` 这类占位符。
- 脚本只做「打开页面 → 读文本/图片 → 输出文案」，不绕过登录、不破解风控、不批量刷接口。请遵守目标平台的服务条款与当地法规。
- 与淘宝、天猫、京东及任何推广平台均无关联。
